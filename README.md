# AstrBot 翻译助手插件

- **作者**：云晓
- **版本**：1.1.1
- **许可证**：MIT（详见 [LICENSE](LICENSE)）

AstrBot 翻译插件：中英及常见语种互译，使用国内可直连的免费翻译接口（无需 API key），自动检测语言，支持指定翻译方向。v1.1.0 新增语种检测指令、长文自动分段翻译、翻译缓存与统计报表。

## 功能

### 自动翻译
```
/翻译 hello world        # 自动检测为英语，翻译为中文
/翻译 你好世界            # 检测为中文，翻译为英文
```
自动方向规则：中文文本 → 英文；其他语种 → 中文。

### 指定翻译方向
```
/翻译 英>中 hello world   # 英语 → 中文（中文简称）
/翻译 en>zh hello world   # 英语 → 中文（语种代码）
/翻译 英语>中文 hello     # 英语 → 中文（中文全称）
/翻译 zh>ja 你好          # 中文 → 日语
```
方向写法支持语种代码（`en`）、中文全称（`英语`）、中文简称（`英`），分隔符支持 `>`、全角 `＞`、箭头 `→`。

### 语种检测（v1.1.0）
```
/翻译 检测 こんにちは      # 显示检测语种：日语 (ja)
```

### 长文分段翻译（v1.1.0）
- 文本超过单段上限（`trans_max_chars`）时自动按句子/换行切分为多段依次翻译并拼接
- 最大段数可配（`trans_max_segments`，默认 5），超出部分截断并提示
- 关闭 `trans_segment_enabled` 后退回旧的整段截断行为

### 翻译缓存（v1.1.0）
- 相同「文本 + 方向」重复翻译直接返回缓存结果，不重复请求接口
- 缓存上限可配（`trans_cache_size`，默认 500 条），超限淘汰最早条目

### 翻译统计（v1.1.0）
```
/翻译 统计                # 累计次数 / 缓存命中率 / 目标语种分布 Top5
```
统计持久化到 `plugin_data/astrbot_plugin_translator/translator_stats.json`。

### 帮助
```
/翻译 帮助                # 查看语种支持列表与用法
/翻译                     # 空参数同样显示帮助
```

## 依赖

- AstrBot 核心库（v4.x）
- 仅使用 Python 标准库（`urllib`、`json`、`re`），无第三方依赖

## 翻译接口

翻译逻辑抽象为 `_translate(text, src_lang, dst_lang)` 方法，可替换实现：
- 默认调用 Google `translate.googleapis.com` 免费接口（`client=gtx`，无需 API key）
- 请求失败或返回空结果时返回 `None`，上层回复"翻译服务暂时不可用，请稍后再试"
- 只依赖标准库 `urllib.request`，不引入第三方 HTTP 库

## 配置

见 `_conf_schema.json`，可在 AstrBot 管理面板中修改：

- `default_target`：自动翻译时默认目标语种（默认留空 = 自动：中文→英文，其他→中文）。示例：`en`、`英语`、`英`、`zh`。非法值自动回退
- `trans_max_chars`：单段翻译最大字符数（默认 `2000`），长文本按此值分段；脏值自动回退默认值
- `trans_segment_enabled`：长文自动分段翻译开关（默认 `true`），关闭后退回截断行为
- `trans_max_segments`：分段翻译最大段数（默认 `5`，范围 1~20）
- `trans_cache_enabled`：翻译结果缓存开关（默认 `true`）
- `trans_cache_size`：缓存最大条目数（默认 `500`，范围 1~10000）
- `trans_stats_enabled`：翻译统计开关（默认 `true`）

## 使用示例

```
/翻译 hello world
🌐 翻译（英语 → 中文）
━━━━━━━━━━━━━━━━━━━━━
📄 原文：hello world
💬 译文：你好，世界
```

## 指令说明

| 指令 | 说明 |
|------|------|
| `/翻译 <文本>` | 自动检测语言并翻译（中文→英文，其他→中文） |
| `/翻译 英>中 <文本>` | 指定翻译方向（支持代码/全称/简称多种写法） |
| `/翻译 检测 <文本>` | 检测文本语种（中/日/韩/英） |
| `/翻译 统计` | 累计次数 / 缓存命中率 / 目标语种分布 Top5 |
| `/翻译 帮助` | 查看帮助与语种列表 |
